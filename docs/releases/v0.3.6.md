## What's Changed

- Auto-detect input color space on open: ICC from TIFF/PNG/JPEG (nearest of sRGB / Display P3 / Linear Rec.709 / Linear Rec.2020)
- RAW and untagged float TIFF/EXR default to Linear Rec.2020; untagged LDR defaults to sRGB
- Plugin Input Color Space follows the detected space; status line shows it
- Silence stb `sprintf` deprecation warning on build
