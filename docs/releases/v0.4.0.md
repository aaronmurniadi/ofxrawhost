## What's Changed

- Release: Windows and Linux are packaged again. Windows ships one self-contained
  `OfxRawHost-Windows-x64.exe`, and Linux ships `OfxRawHost-Linux-x86_64.AppImage`
- Export: WebP and JPEG XL output, with a dialog for the encoder settings
- Export: 16-bit TIFF again, with the ICC profile embedded
- Windows: the executable needs no DLL beside it and opens no console window, and
  links in the terminal that starts it when there is one
- Windows: the bundled Transform effect and the icon font live inside the executable
- Linux: the AppImage carries the host, the Transform plugin, and every library it needs
- macOS: the release build installs the WebP and JPEG XL dependencies it requires
- Packaging: every release runs the self-test from the shipped artifact before upload
