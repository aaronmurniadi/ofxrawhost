## What's Changed

- Windows: a start-up failure now shows a message box instead of leaving the user
  without a window and without a reason
- Windows: the host retries with a legacy OpenGL context when the machine has no
  OpenGL 3.3 driver, which a virtual machine or a remote desktop session often lacks
- UI: the interface draws through the OpenGL2 backend on such a context, so the
  window opens instead of exiting
- UI: no ellipsis character in labels, buttons, hints, and status messages; three dots appear instead
- Packaging: the release smoke test covers the legacy OpenGL path as well
