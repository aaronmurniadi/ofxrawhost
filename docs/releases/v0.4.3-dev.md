## What's Changed

- Linux: the AppImage carries update information, so AppImageUpdate and
  `appimageupdatetool` update it in place instead of asking you to download the
  whole file again
- Linux: the release publishes the `.zsync` file that those tools read. The
  update information points at the newest stable release, so a pre-release build
  is offered the next stable release rather than the next pre-release
- Linux: an AppImage downloaded before this release carries no update
  information, so download this build once to start receiving in-place updates
- README: the Linux section names the update command
