## What's Changed

- UI: a new Settings window opens from the main menu bar, with a section sidebar
  beside the settings panel
- UI: the interface font is bundled Inter, so it looks the same on every
  platform, and the Font section sets the size with a point size and a step
  button; the size follows the operating system font size (the Segoe UI message
  font on Windows, the system font size on macOS, the GTK font size on Linux)
  until the user sets a size of their own, so a new install looks native
- UI: the settings persist in a per-user `settings.json`
  (`%APPDATA%\OfxRawHost`, `~/Library/Application Support/OfxRawHost`, or
  `$XDG_CONFIG_HOME/ofxrawhost`), so the theme, font, and panels survive a
  restart even with no workspace open; the ImGui layout `.ini` moves to the same
  directory
- UI: a long parameter or setting name is elided with an ellipsis and shows in a
  tooltip, and the parameter label column and the settings sidebar follow the
  panel and modal width instead of a fixed size
- UI: a parameter dropdown applies the highlighted option as soon as the user
  steps through the list with the arrow keys, so the plugin and the preview
  follow the highlight before Enter or a click
- Color: the host tracks three spaces. The file space is the tag the file
  declares and only travels in the sidecar and the export metadata; the working
  space is the space of the decoded buffer (linear for RAW, EXR and PNG/JPEG,
  because stb removes the transfer curve while it converts to float, and the tag
  itself for an integer TIFF whose samples stay stored); the input space is what
  the chain is told the image is in, and it starts at the working space
- Color: the chain is walked in order. The first plugin is given the input space
  and every later plugin is given the space the previous plugin declares, so a
  plugin that changes its output feeds the next plugin the new space, and a
  plugin that declares no output space passes the space through unchanged. The
  space that leaves the last plugin is what the preview and the export start
  from
- UI: a new Input colorspace control in the Plugins panel picks the space handed
  to the first plugin, per image, and the sidecar restores it; Rec.709 is the
  default for a RAW file
- UI: Preview colorspace is the destination of the last conversion, not a source.
  The host encodes the chain output into it and shows those values, so the
  preview matches what a file in that space holds in a viewer without color
  management: sRGB (the default) is unchanged, Display P3 differs slightly, and
  a linear choice shows dark mid-tones. Bumping Preview colorspace only recolors
  the cached display, so it needs no re-render
- UI: Export colorspace and Intent (Perceptual, Relative colorimetric,
  Saturation, or Absolute colorimetric) live in the export dialog and default to
  sRGB and Perceptual; the export converts the chain output from the chain output
  space into the Export colorspace with that intent before it writes the file
- UI: two smaller buttons sit above the parameter list, one that imports a
  `.spkpreset` and one that returns every parameter to its plugin default; the
  reset asks for confirmation first, because one click discards the whole edit
- UI: the first run docks the Plugins panel above the Parameters panel in the
  right column, one third over two thirds; ImGui saves the layout, so a later
  run keeps whatever arrangement the user set
- UI: the two docked panels and their View menu items are named `Plugins` and
  `Parameters`, because both are docked in the right column
- UI: a theme changes colors only; every theme keeps the same widget metrics, so
  switching to Soft Cherry, Deep Dark, or Future Dark no longer resizes the
  interface
- UI: a modal overlay is always neutral gray, so Deep Dark no longer tints the
  whole interface red while Settings, About, Donate, or Export is open
- UI: the export converts the chain output from the chain output space into the
  Export colorspace with the chosen Intent before it writes the file
- Packaging: a push to a `release/vX.X.X` branch publishes the tag
  `vX.X.X-dev-<short sha>` as a pre-release, so each pre-release keeps its own
  tag; a `vX.X.X` tag on `main` publishes the stable release
- spektrafilm: an Import *.spkpreset button above the parameter list reads a
  `.spkpreset` file, decodes its snapshot, and applies the values to the node
  while keeping the host input and output color space
- RAW: a camera RAW file without an ICC profile defaults to Linear Rec.709
  instead of Linear Rec.2020
- UI: the Plugins and Parameters panels replace the left/right panel names in
  code and settings; an older project that stored `showLeft`/`showRight` still
  applies
- UI: the Parameters panel drops its own plugin tabs; the node list in the
  Plugins panel decides which parameters are shown, and the panel names the
  selected plugin
- UI: Donate moves to its own top-level menu, and Help becomes About with the
  release version
- Transform: the bundled Crop and Zoom parameters merge into one Zoom control
  that shrinks the output region and keeps samples one to one; projects saved
  before the merge keep the field of view they showed
- Plugins: a bundled Auto Exposure effect meters the frame with the spektrafilm
  methods (average, median, center weighted, partial, matrix, multi zone, and
  highlight weighted), then applies one gain toward 18.4% gray
- Export: the default file name gets an `_export` suffix, so the first export
  never overwrites the original image
- Preview: the default size is "Fit to preview", which renders the preview at the
  pixel size of the preview panel and re-renders when that panel is resized
