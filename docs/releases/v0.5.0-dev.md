## What's Changed

- UI: a new Settings window opens from the main menu bar, with a section sidebar
  beside the settings panel
- UI: the Fonts section selects the UI font family from the system fonts and the
  UI font size from 8 pt through 18 pt
- UI: the font choice persists in the workspace project and in the sidecar files
- Packaging: a push to a `release/vX.X.X` branch publishes the tag `vX.X.X-dev`
  as a pre-release; a `vX.X.X` tag on `main` publishes the stable release
