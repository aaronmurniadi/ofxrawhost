## What's Changed

- Race fixes: wait for the render worker to go idle before swapping the image or rewriting the preview, keep preview renders and graph mutations out of a full-resolution export, make the output tag atomic, and guard instance dimensions and parameter values with mutexes
- ThreadSanitizer-clean concurrency, backed by new concurrency self-test cases (render worker vs. graph mutation vs. export)
- Code cleanup: dedupe helpers, split the Actions module, drop dead code
- Build: patch the OFX support library's log-indent counter to `thread_local`, since action dispatch from the render and UI threads raced on it
